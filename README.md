# Буфер by mysik

Windows помнит только последнее, что вы скопировали. «Буфер» помнит всё: текст, ссылки, картинки и файлы — и возвращает их за секунду.

**Страница программы и скачивание:** https://mysik-portfolio.vercel.app/soft/bufer.html

## Что умеет

- **Ctrl+Shift+V** — список последних копий рядом с курсором. Стрелки и Enter или цифры 1–9.
- **Поиск и фильтры** — по всей истории: текст, ссылки, картинки, файлы.
- **Откуда скопировано** — видно приложение: Chrome, Telegram, Word…
- **Закреплённое** — реквизиты, адрес, шаблоны ответов — всегда сверху.
- **500 записей** — история сохраняется после перезагрузки.
- **Пароли не хранятся** — копии из KeePass, Bitwarden и других менеджеров паролей пропускаются.

## Как начать

Нужна только Windows 10 или 11 — компилятор .NET Framework 4.x уже встроен в систему.

1. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP**, и распакуйте.
2. Запустите `build.bat` — через пару секунд рядом появится `Bufer.exe`.
3. Откройте `Bufer.exe`. Права администратора не нужны.
4. **Включите «Запускать вместе с Windows».** Программа будет работать в трее.
5. **Копируйте как обычно.** А когда нужно что-то старое, нажмите Ctrl+Shift+V.

## Полезно знать

- Вся история хранится только на вашем компьютере, в папке %APPDATA%\Bufer by mysik.

Файлы: `Bufer.cs`, `MainWindow.xaml`, `README.txt`, `Shell.cs`, `Theme.xaml`, `app.ico`, `app.manifest`, `build.bat`.
